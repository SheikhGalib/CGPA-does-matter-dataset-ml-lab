# Shared final-workflow support files

This folder contains the shared coding helper, requirements file, and fixed train/test row indices used by the final WEKA workflow.

Use [`../weka-final/evidence`](../weka-final/evidence) as the authoritative result source for the final presentation and updated report. The final WEKA release excludes six target-conditioned SGPA imputations from every model, uses 1,102 modelling rows, and records every current setting in [`../docs/WEKA_LATEST_OPERATIONS.md`](../docs/WEKA_LATEST_OPERATIONS.md).

The older generated analyses and screenshots were omitted from the publication copy so they cannot be confused with the final results.
